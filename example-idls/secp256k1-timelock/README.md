# secp256k1-timelock

> ⚠️ **Hand-written example. This IDL was not generated by `ckb-idl-derive`.** It is a reference illustration of what the macro output would look like for this lock script pattern.

**Lock type:** Time-locked secp256k1  
**Source:** —  
**Status:** Hand-written example

## Witness layout

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `signature` | `secp256k1_sig` | yes | 65-byte ECDSA signature (r \|\| s \|\| v) |
| `unlock_time` | `uint64` | yes | Unix timestamp before which the cell cannot be spent |

## Notes

- `unlock_time` is in the witness (not args) so the same script bytecode can serve cells with different time locks.
- The script reads `unlock_time` from the witness and compares it against the transaction's `since` field or the header timestamp.
- Args carry the owner's public key hash (32 bytes).
