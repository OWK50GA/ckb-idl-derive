**Lock type:** 2-of-2 multisig with replay-protection nonce  
**Source:** —  
**Status:** Hand-written example

## Witness layout

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `sig_a` | `secp256k1_sig` | yes | Signature from the first co-signer |
| `sig_b` | `secp256k1_sig` | yes | Signature from the second co-signer |
| `nonce` | `uint32` | yes | Replay-protection nonce matching cell data |

## Notes

- Both signatures are required — this is a strict 2-of-2, not a threshold scheme.
- The nonce prevents a valid witness from being replayed against a future cell with the same lock script.
- Args: two 32-byte public key hashes concatenated (64 bytes total).
- This is a good test case for the PSCT format: two independent signers must each contribute one signature before the transaction can be finalised.
