# Example IDLs

> **These IDLs are hand-written examples. They were not generated by `ckb-idl-derive`.**
>
> They exist to illustrate what the IDL output is expected to look like for different lock script patterns, and to give contributors a reference when writing witness structs for real scripts.
>
> IDLs generated by running `#[derive(CkbWitness)]` on actual lock scripts will be added here as real scripts are tested. Each real entry will clearly state the source repository and that the IDL was machine-generated.

---

## How a real IDL gets added here

1. A lock script crate adds `ckb-idl-derive` as a dependency and annotates its witness struct with `#[derive(CkbWitness)]`.
2. `cargo build` runs the macro and writes `idl.json` to `$OUT_DIR`.
3. The generated `idl.json` is copied here into a subfolder named after the script.
4. The subfolder includes the witness struct source, the generated IDL, a link to the script repository, and a note confirming the IDL was machine-generated.
