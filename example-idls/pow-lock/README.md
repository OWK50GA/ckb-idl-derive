## Witness layout

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `difficulty` | `uint8` | yes | Required difficulty (leading zero bits); must match args[0] |
| `proof` | `bytes` | yes | Variable-length proof-of-work nonce |

## Notes

- This script is intentionally contrived — its purpose is to exercise the `u8` → `uint8` and `Vec<u8>` → `bytes` registry mappings, which are not covered by the other scripts in this collection.
- Together with the other three scripts, this IDL collection covers all seven type mappings in the v1 registry: `uint8`, `uint32`, `uint64`, `secp256k1_sig`, `secp256k1_pubkey`, `schnorr_sig`, `bytes`.
- The `bytes` type for `proof` is a known v1 limitation: the IDL does not describe how the variable-length field is framed in the witness (length-prefixed vs remainder). This is documented in the challenges file.
